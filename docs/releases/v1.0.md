# v1.0

## 版本目标

LexiMiner v1.0 作为重构后的定版结构，目标是让项目具备稳定、清晰、可迁移的分析能力边界。

## 运行方式

### 1. 安装依赖

```bash
pip install -r requirements.txt
```

### 2. 启动后端

```bash
python backend/app.py
```

默认地址：`http://127.0.0.1:5000`

### 3. 打开前端

直接访问同一服务根路径：`http://127.0.0.1:5000/`

## 接口说明

### 健康检查

`GET /api/leximiner/health`

返回示例：

```json
{
  "status": "ok",
  "service": "LexiMiner API"
}
```

### 文本分析

`POST /api/leximiner/analyze`

请求体示例：

```json
{
  "text": "Academic reading improves writing skills.",
  "use_online_translation": false
}
```

返回内容：

- `status`
- `message`
- `summary`
- `words`
- `phrases`

## 兼容说明

- `models/` 与 `utils/` 目前仅作为兼容层
- `leximiner_core/` 是核心协议与稳定能力层
- `core/` 负责算法实现细节
